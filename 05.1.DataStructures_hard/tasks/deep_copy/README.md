# DEEP COPY

`copy` `recursion` `dict` `list` `tuple` `set` `frozenset` `memory` `aliasing`

## Условие

Реализуй функцию `deep_copy(obj)`, которая возвращает глубокую копию объекта.

Глубокая копия -- это новая структура, которую можно менять независимо от оригинала.

**Поддерживаемые типы** (вход гарантированно состоит только из них):

- `dict`, `list`, `tuple`, `set`, `frozenset`
- `int`, `float`, `bool`, `str`, `None`

**Требования:**

- по времени — **O(N)**, где `N` — суммарное число элементов во всех вложенных контейнерах;
- по памяти — **O(N)**;
- входную структуру не мутировать;
- запрещено использовать `copy` и другие готовые библиотеки копирования.

**Сохраняй алиасинг.**

Если в оригинале два поля ссылаются на один и тот же изменяемый объект,
то в копии они должны ссылаться на один и тот же новый объект:

```python
shared = [1, 2]
original = {"a": shared, "b": shared}

copied = deep_copy(original)

assert copied["a"] is copied["b"]   # алиасинг сохранен
assert copied["a"] is not shared    # но это уже новый объект
```

**Иммутабельные листья можно переиспользовать.**

`int`, `float`, `bool`, `str`, `None` не имеют внутренней структуры,
их копия неотличима от оригинала, поэтому копировать их не нужно:

```python
x = 5
assert deep_copy(x) is x
```

`frozenset` тоже можно возвращать по ссылке: его элементы обязаны быть
хешируемыми, а значит (для поддерживаемых типов) иммутабельными насквозь.
`tuple` так делать нельзя: он может содержать мутабельные объекты внутри,
даже если сам tuple нельзя изменить по индексу.

**Примечание**

Циклические ссылки (когда объект ссылается сам на себя) в этой задаче не рассматриваются.

## Пример

```python
>>> shared = [1, 2]
>>> original = {"a": shared, "b": shared, "c": [3, {"d": 4}]}
>>> copied = deep_copy(original)

>>> copied == original
True

>>> copied is original
False

>>> copied["a"] is copied["b"]
True

>>> copied["a"] is shared
False

>>> copied["c"] is original["c"]
False

>>> copied["c"][1] is original["c"][1]
False
```

## Про задачу

Полезно на практике разобраться, как работает `deep copy`.
Заодно эта задача хорошо показывает разницу между значением объекта и ссылкой
на него, и чем `shallow copy` отличается от `deep copy`.
