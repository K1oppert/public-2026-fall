# ANAGRAMS AND BEYOND

`dict` `tuple` `frozenset` `embedding` `interview`

## Условие

Дан список слов. Гарантируется, что слова состоят только из строчных
латинских букв.

Реализуй три функции:

1. `group_anagrams(words)`  
   Группирует слова, которые являются анаграммами друг друга.  
   Например, `"eat"`, `"tea"` и `"ate"` должны попасть в одну группу.

   Требования:
   - по времени — **O(n · L log L)**, где `n` — число слов, `L` — длина слова;
   - по памяти — **O(n · L)**.

2. `group_anagrams_linear(words)`  
   Решает ту же самую задачу, что и первая функция, но быстрее.

   Требования:
   - по времени — **O(n · L)**;
   - по памяти — **O(n · L)**.

3. `group_words_by_unique_letters(words)`  
   Группирует слова по множеству различных букв.  
   Повторения букв не учитываются.

   Например, `"ab"` и `"aab"` не являются анаграммами,
   но должны попасть в одну группу, потому что множество различных
   букв у них одинаковое: `{'a', 'b'}`.

   Требования:
   - по времени — **O(n · L)**;
   - по памяти — **O(n · L)**.

**Общие требования:**

- входной список не мутировать;
- каждая функция возвращает `list[list[str]]`;
- порядок групп и порядок слов внутри групп не важен;
- пустой список слов дает пустой список групп;
- пустая строка считается словом без букв.

**Важно.**  
Первые две функции решают одну и ту же задачу -- группировку анаграмм.
Они отличаются только временем работы.

Третья функция решает другую задачу: группировку по множеству букв.
Поэтому на словах с повторяющимися буквами ее результат обязан
отличаться от результата первых двух функций.

**Подсказка к `group_anagrams`.**  
Сложность **O(n · L log L)** намекает, что над каждым словом можно
выполнить сортировку.

**Подсказка к `group_anagrams_linear`.**  
Сложность **O(n · L)** намекает, что слово нужно обработать за один
линейный проход. Подумай, какой признак слова не зависит от порядка
букв и может быть представлен в виде хэшируемого объекта.

## Пример

```python
>>> words = ["eat", "tea", "tan", "ate", "nat", "bat"]

>>> sorted(sorted(group) for group in group_anagrams(words))
[['ate', 'eat', 'tea'], ['bat'], ['nat', 'tan']]

>>> sorted(sorted(group) for group in group_anagrams_linear(words))
[['ate', 'eat', 'tea'], ['bat'], ['nat', 'tan']]

>>> words = ["ab", "ba", "aab", "aba"]

>>> sorted(sorted(group) for group in group_anagrams(words))
[['aab', 'aba'], ['ab', 'ba']]

>>> sorted(sorted(group) for group in group_words_by_unique_letters(words))
[['aab', 'ab', 'aba', 'ba']]
```

## Про задачу

Анаграммы -- это упрощенная модель нормализации текста, где порядок
элементов игнорируется, а объект превращается в признак, по которому
его можно сравнивать с другими объектами.

Вторая функция (предполагаемая реализация) фактически строит для каждого слова вектор частот букв.
Это очень похоже на идею **bag of words** в обработке текстов:
документ представляется как вектор частот слов, а порядок слов
игнорируется. Дальше такие векторы можно сравнивать, взвешивать и
использовать в поиске.

Более известный вариант этой идеи -- **TF-IDF**:

$$
\text{tf-idf}(t, d, D)
=
\text{tf}(t, d)
\cdot
\log \frac{|D|}{\text{df}(t)}
$$

где:

- `t` — терм, например слово;
- `d` — документ;
- `D` — корпус документов;
- `tf(t, d)` — частота терма в документе;
- `df(t)` — число документов, в которых встречается терм;
- `|D|` — размер корпуса.

Практический пример -- дедупликация поисковых запросов. Запросы
`"купить джинсы"` и `"джинсы купить"` часто нужно считать одинаковыми,
чтобы не задваивать статистику и не считать одни и те же метрики
несколько раз. Анаграммы -- игрушечная версия такой нормализации.
