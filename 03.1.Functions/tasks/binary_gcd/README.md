## BINARY GCD

`recursion` `bit operations` `gcd`

### Условие

**Алгоритм Штейна** — это метод нахождения **наибольшего общего делителя (НОД)** двух целых чисел, который использует только битовые операции (сдвиги) и вычитание, избегая операции деления.

В отличие от классического алгоритма Евклида (основанного на делении с остатком), алгоритм Штейна опирается на свойства чётности чисел:

1. **Оба числа чётные:** `НОД(a, b) = 2 * НОД(a/2, b/2)`
2. **Одно чётное, другое нечётное:** `НОД(a, b) = НОД(a/2, b)` (чётное делится на 2)
3. **Оба нечётные:** `НОД(a, b) = НОД(|a - b|, min(a, b))` (используется вычитание)
4. **Базовый случай:** если одно из чисел равно 0, ответ — второе число.

Реализуйте рекурсивную функцию `binary_gcd(a, b)`, корректно возвращающую НОД чисел `a` и `b` в диапазоне от `0` до `1_000_000_000_000`.

Пользоваться модулем `math` (в том числе `math.gcd`) нельзя.

### Пример

```python
>>> binary_gcd(48, 18)
6
>>> binary_gcd(0, 5)
5
>>> binary_gcd(0, 0)
0
```

### Про задачу

В Python-арифметике алгоритм не очень полезен, так как в интерпретаторе доминируют другие действия.

Однако он может пригодиться в NumPy — там битовые операции и сдвиги выполняются над целыми массивами данных быстрее,
чем поэлементное деление, что даёт реальный выигрыш в производительности при работе с большими объёмами чисел.
