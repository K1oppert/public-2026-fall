## MEMOIZE LAST

`closure` `nonlocal` `scope` `cache`

### Условие

Полноценный LRU-кэш из стандартной библиотеки использует словарь.

Мы же реализуем усеченную, но по-своему полезную версию: кэш, который
помнит только самый последний вызов. Она пригодится там, где
одна и та же функция часто вызывается несколько раз подряд с одним и
тем же аргументом (типичный пример — повторные обращения к последнему
результату в цикле).

Функция `memoize_last(f)` возвращает пару `(wrapper, calls_made)`:

* `wrapper(x)` — обёртка над `f`:
  * если `x` совпадает с аргументом **предыдущего** вызова — вернуть
    запомненный результат, не вызывая `f` повторно;
  * иначе — вызвать `f(x)`, запомнить и `x`, и результат (вместо
    предыдущей запомненной пары), вернуть результат.
* `calls_made()` — сколько раз `f` была реально вызвана (без учёта
  "попаданий в кэш").

Никакого словаря/списка и `functools`: состояние — это последний аргумент,
последний результат и счётчик, каждый в своей переменной замыкания.

Обратите внимание: `None` — тоже допустимый аргумент, и самый первый вызов `wrapper(None)`
должен честно вызвать `f`.

### Пример

```python
log = []
def slow(x):
    log.append(x)
    return x * x

f, calls_made = memoize_last(slow)
f(3)   # считает: log == [3]
f(3)   # берёт из кэша: log всё ещё == [3]
f(4)   # считает заново (аргумент другой): log == [3, 4]
f(3)   # снова считает: в кэше уже "4", а не "3": log == [3, 4, 3]
calls_made()   # 3
```
