## MAKE ADDER

`closure` `currying` `default arguments` `sentinel`

### Условие

Реализуем сложение через цепочку вызовов произвольной длины:
`adder(1)(2)(3)()` должен вернуть `6`. Каждый вызов с числом
продолжает цепочку и запоминает ещё одно слагаемое; вызов совсем без
аргументов эту цепочку завершает и возвращает накопленную сумму.

Функция `make_adder()` возвращает функцию `adder`:

* `adder(x)`, где `x` — число: возвращает **новую** функцию того же
  вида, которая при последующем вызове помнит `x` вдобавок ко всем
  числам, переданным раньше в этой цепочке;
* `adder()` — без аргументов: завершает цепочку и возвращает
  сумму всех чисел, переданных на предыдущих шагах (для ещё не
  начатой цепочки — `0`).

Не должно быть списка, в котором накапливались бы слагаемые: каждый шаг —
просто новое замыкание с уже готовой частичной суммой внутри.
Состояние не должно храниться в `nonlocal`-переменной, которую можно
случайно "испортить" повторным использованием — у каждого вызова
`adder(x)` должно получаться самостоятельное, независимое от
остальных продолжение цепочки.

### Пример

```python
chain = make_adder()
chain(1)(2)(3)()      # 6
chain(5)(10)()        # 15
chain()               # 0 - цепочка, сразу завершённая

# каждый вызов make_adder() начинает независимую цепочку;
# промежуточный результат нужно сохранить, чтобы её продолжить:
a = make_adder()
b = make_adder()
a = a(1)(2)
b = b(100)
a(3)()      # 6   (1 + 2 + 3)
b(1)()      # 101 (100 + 1, никак не связано с цепочкой a)
```
