## INT SQRT

`recursion` `binary search` `recursion limit`

### Условие

Реализуйте функцию `int_sqrt(n)`, возвращающую наибольшее целое `k`, такое что `k * k <= n` (`0 <= n <= 1_000_000_000_000`).

Через рекурсивный бинарный поиск по диапазону `[0, n]`,
без использования модуля `math` (`math.sqrt`, `math.isqrt`) и без перебора.

### Пример

```python
>>> int_sqrt(0)
0
>>> int_sqrt(1)
1
>>> int_sqrt(15)  # 3*3=9 <= 15, а 4*4=16 > 15
3
>>> int_sqrt(1_000_000_000_000)
1000000
```

### Про задачу

Подумайте, какой будет глубина рекурсии для максимального `n` и почему она не упирается в `sys.getrecursionlimit()`.
