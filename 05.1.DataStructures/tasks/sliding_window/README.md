# SLIDING WINDOW

`deque` `interview`

## Условие

Дан список чисел `nums` и размер окна `k`.

Нужно пройтись по списку слева направо и для каждого окна размера `k`
вернуть максимум внутри этого окна.

Например, если `nums = [2, 4, 1, 7, 3]` и `k = 3`,
то окна будут такими:

```text
[2, 4, 1]  -> max = 4
[4, 1, 7]  -> max = 7
[1, 7, 3]  -> max = 7
```

Значит, ответ: `[4, 7, 7]`.

**Требования:**

- по времени — **O(n)**, где `n = len(nums)`;
- по памяти — **O(k)**;
- входной список не мутировать;
- наивное решение с `max(nums[i:i + k])` на каждом шаге не принимается.

Используйте в решении `collections.deque`.

**Краевые случаи:**

Если `nums` пустой, `k <= 0` или `k > len(nums)`, вернуть пустой список.

## Пример

```python
>>> sliding_window_max([2, 4, 1, 7, 3], 3)
[4, 7, 7]

>>> sliding_window_max([1, 2, 3], 1)
[1, 2, 3]

>>> sliding_window_max([1, 2, 3], 3)
[3]

>>> sliding_window_max([1, 2], 5)
[]

>>> sliding_window_max([], 3)
[]
```

## Про задачу

Скользящий максимум -- стандартная операция над потоком данных.
Неважно, что мониторить: температуру, цену актива или нагрузку на сервер.
Просто хочется знать пик за последние K значений.

Поток обычно большой, окно сдвигается по одному элементу. Если каждый раз
заново пересматривать все K значений, суммарно получается очень медленно.
Хочется обновлять ответ за константу на каждый новый элемент.
