## SAFE PIPELINE

`closure` `composition` `higher-order functions` `early exit`

### Условие

Тот же принцип построения цепочки, что и в задаче `pipeline`, но контракт
функций теперь другой: любая функция в конвейере может вернуть `None`,
и это означает "здесь ошибка, дальше идти нельзя". Как только это
случилось, конвейер должен **остановиться**: ни одна из последующих
функций в цепочке вызываться не должна, а весь конвейер сразу
возвращает `None`.

Функция `safe_pipeline(f)` возвращает функцию `add`:

* `add(g)`, где `g` — функция одного аргумента: возвращает **новую**
  функцию того же вида ("продолжение конвейера"), в которой `g`
  добавлена в конец цепочки;
* `add()` — без аргументов: завершает цепочку и возвращает готовую
  функцию одного аргумента — композицию всех функций, переданных
  в `safe_pipeline` и во все `add`, в том порядке, в котором их добавляли.

Контракт функций-шагов:

* каждая функция в цепочке принимает один аргумент и возвращает
  либо результат, либо `None` как признак ошибки;
* если очередная функция в цепочке вернула `None`, готовая функция
  конвейера должна **сразу** вернуть `None`, не вызывая ни одной из
  оставшихся функций;
* если ошибок не было, готовая функция возвращает результат
  последнего шага как обычно (в том числе он тоже может
  оказаться `None`, если ошибка произошла именно на последнем
  шаге — дальше вызывать уже некого);
* `None` на **входе** конвейера ошибкой не считается — его получает первая функция.

### Пример

```python
def half_if_even(x):
    return x // 2 if x % 2 == 0 else None

def add_one(x):
    return x + 1

def positive_only(x):
    return x if x > 0 else None

p = safe_pipeline(half_if_even)(add_one)(positive_only)()

p(10)    # 6   -> half_if_even(10)=5, add_one(5)=6, positive_only(6)=6
p(3)     # None -> half_if_even(3) вернула None, add_one и positive_only
         #         не вызываются вовсе
p(-4)    # None -> half_if_even(-4)=-2, add_one(-2)=-1,
         #         positive_only(-1)=None (проверка сработала на
         #         последнем шаге)
```

### Алгебра над функциями

Это не задание, просто мысли.

Конвейер — частный случай более общей идеи: комбинировать функции,
превращая группу функций в одну. Помимо последовательной композиции
(`pipeline`), можно добавить операцию `first_of` — применить функции
по очереди и вернуть результат первой успешной.

Результат применения любой такой операции — тоже функция.
Её можно передавать дальше, комбинировать и использовать как строительный блок:

```python
p = pipeline(
    first_of(
        lambda x: x if x > 0 else None,
        lambda x: -x if x < 0 else None,
        lambda x: 0,
    )
)(lambda x: x * 2)()

p(-5)  # 10
```

Добавляя другие операции (`all_of`, `maybe`, `map_over`, `filter_with`),
получаем **алгебру над функциями**: набор комбинаторов, из которых
можно собирать сложные структуры обработки данных декларативно,
без состояния и побочных эффектов.
